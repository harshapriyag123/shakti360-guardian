# Product Hunt launch kit

## Listing

**Name:** Shakti360 Guardian  
**Tagline:** Personal safety that adapts to you—without tracking you forever.  
**Description:** Shakti360 combines time-bound safety journeys, trusted guardians, nearby support, scam screening, and private documentation. Its battery-aware policy avoids continuous GPS polling, and users explicitly control escalation.

## Maker comment

We built Shakti360 because personal safety should not require permanent surveillance. Every journey and location-sharing session expires, every automated recommendation is explained, and emergency services are never contacted without the user's explicit action.

## First comment

We would value feedback on three questions: Was the journey flow understandable? Did the privacy boundary feel clear? Which tool would you actually use?

## FAQ

- **Does it automatically call police?** No. It presents call options for the user.
- **Does it track users permanently?** No. Location access is session-based.
- **Is nearby data verified?** It is live community-maintained OpenStreetMap data and may be incomplete.
- **Is this ready for emergencies?** This is a hackathon pilot, not a replacement for emergency services.
