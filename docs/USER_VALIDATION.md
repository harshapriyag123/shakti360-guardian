# User Validation Plan

Do not optimize for signups only. Track meaningful actions:

- unique users
- readiness checks completed
- safety journeys started/completed
- SafeWord test activations
- nearby-resource searches
- Cyber Guardian scans
- incidents documented
- Privacy Guardian checks
- feedback responses
- referral source

## DoraHacks target
- 75+ unique users
- 50+ meaningful sessions
- 20+ feedback responses
- 8+ public testimonials
- 4+ build/launch content pieces

A compelling validation slide is stronger than claiming “24 agents.”
