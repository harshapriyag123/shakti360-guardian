# Shakti360 Agent Map

## Implemented in the starter
1. **Journey Guardian** — temporary safety sessions, ETA and check-ins.
2. **Battery Guardian** — adaptive power modes; no continuous GPS requirement.
3. **Context Fusion Agent** — fuses session conditions without claiming crime prediction.
4. **SafeWord Guardian** — discreet user-configured escalation trigger.
5. **Trusted Circle Agent** — demo-safe notification adapter.
6. **Nearby Help Agent** — hospital/police/pharmacy provider abstraction.
7. **Cyber Guardian** — explainable message risk signals.
8. **Evidence Guardian** — factual incident structuring.
9. **Pattern Agent** — descriptive patterns across user-recorded incidents.
10. **Privacy Guardian** — checks risky privacy configurations.
11. **Safety Readiness Agent** — 60-second onboarding/growth hook.
12. **Impact Analytics Agent** — metrics for DoraHacks validation.

## Production roadmap
- Connectivity Guardian
- Accessibility / voice guardian
- Life-stage adaptive UX agent
- Verified regional resource navigator
- Recovery navigator
- Community safety aggregation
- Community report verification / spam protection

## Boundary
Agents are narrow and explainable. Deterministic code owns safety-critical state transitions.
